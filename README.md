    Customer Shopping Behavior Analysis

## Overview

This project analyzes customer shopping behavior to uncover purchasing patterns, customer preferences, and sales trends. The analysis helps businesses understand customer behavior and make data-driven decisions to improve marketing strategies and customer engagement.

## Tools & Technologies

- Python (Pandas, NumPy)
- PostgreSQL
- SQL
- Power BI

## Project Workflow

### Data Preprocessing
- Cleaned and prepared customer shopping data.
- Handled missing values using median imputation.
- Standardized column names.
- Created new features such as:
  - Age Groups
  - Purchase Frequency (Days)

### Database Integration
- Loaded processed data into PostgreSQL.
- Performed SQL queries for business analysis.

### Data Analysis
- Customer demographic analysis
- Product category performance
- Discount usage analysis
- Purchase frequency analysis
- Customer rating analysis

### Dashboard Development
Built an interactive Power BI dashboard to visualize:

- Total Sales
- Customer Segmentation
- Product Performance
- Discount Impact
- Purchase Trends

## Key Insights

- Identified top-performing product categories.
- Analyzed customer purchasing behavior across age groups.
- Measured the impact of discounts on sales.
- Discovered patterns in customer purchase frequency.
- Generated business insights through interactive visualizations.
